## 五、Dead Code 清理：standard_responses

### 问题发现

`content.js` 中 `collectStandardResponseLabels()` 每次 Capture 会从 Centuran 的标准回复下拉框采集所有选项（实测 63 个），并随每次 API 请求发送至后端。

经追踪全链路：
- **Mock 引擎**：`suggestTemplateFromStructuredData()` 读取后赋值给 `responses` 变量，但该变量从未被使用（死代码）
- **LLM 引擎**：拼入 prompt 上下文，但只有裸名称无描述，LLM 无法有效利用
- **panel.js**：完全未引用

每次请求额外消耗约 300-400 tokens，无任何收益。

### 删除范围

| 文件 | 改动 |
|---|---|
| `extension/content.js` | 删除 `collectStandardResponseLabels()` 函数及全部引用（4 处） |
| `backend/lib/helpers.js` | 删除 `normalizeStructuredThread()` 中的 `available_standard_responses` 字段，删除 `buildStructuredThreadText()` 中的输出块 |
| `backend/lib/mock-engine.js` | 删除 `suggestTemplateFromStructuredData()` 中的死变量 `responses` |

`npm run check` 通过，无语法错误。
